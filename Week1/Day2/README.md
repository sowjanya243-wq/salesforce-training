#  What is Salesforce Platform?

Salesforce Platform is a cloud-based platform used to build CRM applications, automate business processes, manage customer data, and create custom applications.



#  App

An App in Salesforce is a collection of objects, tabs, and tools used for a specific business process.

Example:
College Management App

---

#  Object

An Object is a database table that stores data in Salesforce.

Examples:
- Student
- Faculty
- Course



#  Tab

A Tab is used to open and access objects and records inside Salesforce.

---

#  Configuration vs Coding

## Configuration (No Code)
Configuration means customizing Salesforce without writing code.

Examples:
- Creating fields
- Validation rules

## Coding (Apex)
Coding is used for advanced custom functionality using Apex programming.

Examples:
- Payment gateway integration
- Complex calculations

---

#  Multi-Tenant Architecture

Multi-tenant architecture means many companies use the same Salesforce servers securely while keeping their data separate.

---

#  CRM Concepts in Salesforce
