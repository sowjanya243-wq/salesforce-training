 Day 8 - LWC Basics

## What is LWC?
Lightning Web Components (LWC) is a modern framework in Salesforce used to build reusable and fast UI components.

## Why Salesforce Uses LWC
Salesforce uses LWC because it is faster, reusable, secure, and based on modern web standards.

## UI Screens

## Component Breakdown

- Student Info Component
- Attendance Component

- Notification Component

## Why Reusable Components are Useful
Reusable components save development time and reduce duplicate code.

## Frontend vs Backend Logic

Frontend:
- Button clicks
- Display notifications
- UI interaction

Backend:
- Fee calculation
- Database operations
- Business logic

## Reflection
Modern systems use component-based architecture for scalability, maintainability, and reusability.

## Revision Answers

### 1. What is a component?
A reusable part of a UI.

### 2. Why are reusable components useful?
They save time and reduce duplicate code.

### 3. Difference between frontend and backend?
Frontend handles UI. Backend handles logic and database.

### 4. Why did Salesforce move toward LWC?
For better performance and modern UI development.

### 5. Why is UI important in enterprise systems?
It improves user experience and productivity.

### 6. Why should systems separate UI and business logic?
To make systems easier to maintain and scale.

### 7. What security risks exist in enterprise applications?
Unauthorized access, data leaks, and weak permissions.

### 8. Why should developers think modularly?
It makes applications reusable and easier to manage.
